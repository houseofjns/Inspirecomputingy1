WHAT IS INCLUDED
- The approved House of J&S gold and navy portal design and original logo.
- Six Year 1 learning units with ten lessons each.
- English and Myanmar study explanations at an age-appropriate level.
- Visual learning blocks: tables, simple diagrams, sequence flows, drawing tools and Turtle LOGO code.
- 180 bilingual glossary entries.
- Year 1 Workbook Answer Guide based on the supplied Year 1 Workbook Answers PDF.
- Practice quizzes and a separate unit examination for each unit.
- Local assets and offline service-worker cache.

EXAMINATION
Each unit exam uses the standard House of J&S structure: 84 questions, 100 marks and 60 minutes. It includes 30 multiple-choice, 20 fill-in, 20 matching, 10 short-response and 4 extended-response questions. The extended-response score is provisional and should be reviewed by a teacher. The exam engine is browser-only: fullscreen and navigation warnings are not tamper-proof security.

ANSWER GUIDE SOURCE NOTE
The uploaded document was titled Inspire Computing Year 1 Workbook Answers. Answer text is grouped by unit and lesson. The answer sheet marks some tasks as “Student's own answer”; those remain open-ended. Where a separate lesson heading or answer text was not identifiable in the extracted answer sheet, the portal flags it for teacher verification rather than inventing an official answer.

SOURCE AND COPYRIGHT
The Student Book and Workbook were referenced through the publicly viewable Scribd previews supplied by the user. The complete Student Book text was not available for page-by-page extraction. The study notes are based on visible course topics and the uploaded Year 1 answer sheet, with original bilingual teaching explanations and practice visuals added. This ZIP does not include the original Student Book, Workbook or Answer Sheet PDFs, nor scanned page images.

OFFLINE / GITHUB PAGES
The portal uses HTML, CSS and vanilla JavaScript. For reliable offline caching, first open the site in a browser from a local web server or GitHub Pages (service workers may not work on file:// URLs). The content itself is bundled locally.

TEACHER NOTE
This is a client-side educational portal. The password is stored in JavaScript and is not server-side authentication. Use a managed platform for high-stakes exams or private student records.
